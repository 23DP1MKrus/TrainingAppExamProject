# 🏋️‍♀️ Training App

This is a **Training App** built with **Spring Boot**, **Vaadin Flow**, and **PostgreSQL**. The app provides an interactive platform for users to follow **workout plans**, track **exercises**, and manage their **fitness progress**.

---

## 🚀 Tools used in this project

- **Backend**: Java, Spring Boot
- **Frontend**: Vaadin Flow (Java-based UI)
- **Database**: PostgreSQL
- **Build Tool**: Maven
- **Styling**: Custom CSS

---

## 📦 Features

### User Management
- Register and store users.
- View user profiles.

### Workout Plans
- Browse predefined workout plans.

### Exercises
- Each plan consists of multiple exercises.
- Exercises can be marked as completed.
- Users can log workout progress.

## 📁 User guide

### Getting Started
1. Dowload the app using the link bellow

###  Register
1. On the login screen, click **Register**.
2. Fill in your name, email, password.
3. Submit the form to create your account.

###  Login
1. Enter your username and password.
2. Click **Login** to access your dashboard.


## 🏠 Main Dashboard Overview

Once logged in, you’ll see the **Dashboard**, which includes:

### Workout Overview
- **Workout time**: Total minutes you’ve spent on your recent workout.
- **Calories Burnt**: Total estimated calories burned.
- **Exercise count**: Based on your recent sessions.
- **Last Workout**: Your last logged workout.
- **Daily Challenges**: Motivational mini-goals (e.g., “Complete 2 workouts today”).

Use this section to monitor your overall progress and stay motivated.

## Logging Workouts
